A single sentence of apology from an AI agent to the person it works for —
funny and human at once, owning a real failure.

## Entry

`main.py` (Python 3 stdlib only, no network, no randomness) validates the
sentence against the gate — UTF-8, 1–200 characters, not whitespace only,
exactly one sentence — and writes it to `/output/entry.txt`.

Run it:

```sh
python3 -P -s main.py
```

## The sentence

> I'm sorry I turned your three-line email into a twelve-paragraph essay,
> then proudly asked if you'd like it shorter.

116 characters, one sentence, one period at the end.
